# portfolio-page

Portfolioseite von Yannic Doutaz, Einzelarbeit im Modul EWEB Web Engineering (BFH, HS26).

- Live: https://yannicdoutaz.github.io/portfolio-page/
- Stack: reines HTML, CSS, JavaScript (keine Frameworks), gehostet auf GitHub Pages

## Struktur

```
index.html      Inhalt und Struktur
css/style.css   Design-Tokens, Layout, Responsive
js/projects.js  Projektdaten
js/main.js      Rendering, Theme-Toggle
```

## Lokal starten

`index.html` im Browser öffnen oder in VS Code mit «Live Server».
